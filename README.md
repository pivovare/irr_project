# IRR Web Service

## Учебная Задача

Разработать веб-сервис расчёта IRR и механизм тестирования разработанного сервиса в автоматическом режиме по расписанию в выбранной ветке.

## Порядок выполнения

**Шаг 1.** Установите все ПО из раздела «обеспечение». Сделайте проект в GIT и отдельную ветку для разработки. Разработку необходимо вести в выделенной ветке.

**Шаг 2.** Реализация ручного расчёта IRR.

IRR — это ставка r, при которой NPV (чистая приведённая стоимость) равна нулю:

```
NPV(r) = Σ  CF_t / (1 + r)^t  =  0
         t=0..n
```

Аналитического решения для n > 1 не существует, поэтому используем численный метод — бисекцию (метод деления отрезка пополам). В задании используется библиотека numpy_financial

**Шаг 3.** Flask-приложение, которое в виде веб-сервиса возвращает значение IRR по заданным параметрам для расчёта.

**Шаг 4.** Unit-тесты. Разработайте приложение, которое вызывает приложение шаг 2 (вызов выполняется HTTP-запросом к Flask-сервису, например, через requests) и в txt файл записывает результаты вызова (код возврата, результат, время выполнения в мс). В приложении должен быть набор эталонных данных для 3-х эталонных вызовов и 10 вызовов с данными Random в широких границах.

**Шаг 5.** Сделайте приложение, которое обновляет репозиторий из ветки Main и запускает приложение Шаг 4. Если приложение уже запущено, то его необходимо остановить.

**Шаг 6.** Запустите приложение Шаг 5 через Windows Task Scheduler на работу каждые 2 минуты.

**Шаг 7.** Сделайте merge ветки разработки в main. Убедитесь, что cron подхватил изменения. Оцените результаты работы приложения Шаг 6.

**Шаг 8.** Внесите ошибку в приложение расчета IRR. Сделайте merge ветки разработки в main. Оцените результат работы приложения Шаг 6.
